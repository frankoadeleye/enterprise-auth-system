# EverAfter

EverAfter is a modern memory-preservation web application that helps users store, organize, and revisit life's most meaningful moments.

Users can create memory collections, upload photos, add context to memories, organize experiences by location, and relive those moments through an immersive viewing experience.

## Features (In Progress)

### Landing Page

- Responsive homepage
- Light and dark mode
- Featured collections
- Featured memories
- How EverAfter Works section

### Authentication (Planned)

- User registration
- User login
- Password reset
- Protected routes

### Memory Management (Planned)

- Upload photos
- Add descriptions and context
- Organize memories into collections
- Location tracking (country, state, town)
- Visit dates

### Dashboard (In Progress)

- Dashboard layout
- Sidebar navigation
- Collection management
- Memory management
